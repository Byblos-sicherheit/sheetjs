Demo

🆕 How it works

1. Server returns SDUI config (JSON)
→
2. Client renders table from JSON
→
3. SheetJS exports table to Excel
💡 With SDUI, the table structure (columns, types, data) lives in the server’s JSON. SheetJS reads that same JSON to produce the Excel file — no duplication of schema.

📊 Kunden-Übersicht (from SDUI config)

📄 Code Snippet

// 1. Fetch SDUI config from server const config = await fetch('/api/sdui/config').then(r => r.json()); const tableScreen = config.screens.find(s => s.id === 'kunden'); const tableComponent = findComponent(tableScreen.root, 'data_table'); // 2. Build worksheet from SDUI data_table props const { columns, rows } = tableComponent.props; const headers = columns.map(c => c.label); const data = rows.map(row => columns.map(c => row.cells[c.key]?.value ?? '')); // 3. Export with SheetJS const ws = XLSX.utils.aoa_to_sheet([headers, ...data]); const wb = XLSX.utils.book_new(); XLSX.utils.book_append_sheet(wb, ws, 'Kunden'); XLSX.writeFile(wb, 'kunden-export.xlsx');
